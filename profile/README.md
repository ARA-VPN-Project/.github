## Своя сеть для доступа к нужным сервисам

**ARA VPN** соединяет входные и выходные ноды, правила сервисов, подписки и
ограничения в одной панели. Своя инфраструктура, понятные маршруты, Web UI и CLI.

- **Входной VPS + зарубежный выход** — управляйте всей цепочкой подключения.
- **Домашний вход + Нидерланды** — Debian дома и внешний VPS; для входа домой
  нужен белый IP и роутер с пробросом порта.
- **Один внешний сервер** — начните с прямого VPN и расширяйте сеть позже.
- **Семья или команда** — отдельные устройства и один контролируемый бюджет.
